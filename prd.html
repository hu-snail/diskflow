DiskFlow

磁盘数据迁移与空间管理工具 · PRD v1.0

1. 产品定位

属性描述
产品名称DiskFlow
一句话定位macOS 磁盘空间分析与数据迁移的桌面工具
对标产品DaisyDisk（可视化）+ CleanMyMac（清理）+ OmniDiskSweeper（扫描）
差异化唯一支持符号链接迁移应用数据到外部磁盘的工具
技术栈Rust + Tauri v2 + Vue 3 + TypeScript + Naive UI
目标用户macOS 用户，内部磁盘空间不足，有外接磁盘/移动硬盘

事件名载荷说明

scan:progress{ scanned, total_size }扫描进度
migrate:log{ level, message, time }操作日志
system:metrics{ cpu, mem, disk_io }系统指标（每秒推送）

6. 迁移流程（核心流程）

三重校验迁移流程
1. 用户选择应用/目录 + 目标磁盘
2. Rust 后端启动迁移任务（异步）
   ├─ 2a. 统计源目录文件数和大小
   ├─ 2b. 用 rsync -a 复制到临时目录
   │    └─ 每复制一批文件 emit("migrate:progress", ...)
   ├─ 2c. 三重校验
   │    ├─ 第一层：文件数量对比
   │    ├─ 第二层：总字节数对比
   │    └─ 第三层：rsync --dry-run 内容校验
   ├─ 2d. 校验通过 → 重命名原目录为 .backup
   ├─ 2e. 创建符号链接
   └─ 2f. emit("migrate:log", "迁移成功")
3. 前端实时显示进度条 + 日志
4. 用户验证应用正常 → 点击"清理备份"

7. 数据模型

DiskInfo
struct DiskInfo {
  name: String,           // "Macintosh HD"
  mount_point: String,    // "/"
  total_space: u64,       // bytes
  available_space: u64,   // bytes
  fs_type: String,        // "APFS"
  is_removable: bool,
  is_sparse: bool,        // 稀疏镜像
}
DirNode
struct DirNode {
  name: String,
  path: String,
  size: u64,
  file_count: u64,
  is_dir: bool,
  children: Vec<DirNode>,
}
MigrateResult
struct MigrateResult {
  success: bool,
  source_size: u64,
  target_size: u64,
  file_count: u64,
  verify_passed: bool,
  error: Option<String>,
}
SystemInfo
struct SystemInfo {
  cpu_usage: f32,         // 0-100
  cpu_cores: u32,
  mem_total: u64,
  mem_used: u64,
  disk_read: u64,         // bytes/sec
  disk_write: u64,
  uptime: u64,
}

8. 安全设计

风险缓解措施
误删用户数据删除前必须二次确认 + 备份保留 + 三重校验
迁移中断临时目录方案 + 失败自动清理 + .backup 保留
符号链接断裂目标磁盘格式检测（拒绝 ExFAT/FAT32）
权限不足Rust 原生权限检测 + 用户引导
路径遍历攻击路径规范化 + 白名单验证
